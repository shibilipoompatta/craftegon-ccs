# CraftEgon Corporate Services (CCS)

Enterprise-grade digital corporate infrastructure, compliance portals, and multi-vertical professional service directory.

## Repository Structure
- `/assets/`: Global CSS design tokens, reset styles, and JavaScript modules (navigation, fee calculators, and intake forms).
- `/components/`: Reusable HTML partials (Navbar mega-menu, 15-vertical dynamic footer).
- `/verticals/`: Top-level vertical hubs (01 Entity Formation through 15 IT & Digital Compliance).
- `/services/`: Flat directory of specialized service pages across all verticals.
- `/knowledge/`: Regulatory blueprints, step-by-step guides, and calculators.
- `/conversion/`: Interactive intake forms, checkout funnels, and diagnostic tools.
