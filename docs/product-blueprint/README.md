## 4. Operational Principles

1. **Evidence-Based Grounding**: Every regulatory obligation, form requirement, and fee formula must cite its governing statutory section and official gazette notification.
2. **Zero Fake State**: The platform never fabricates submission receipts, pretends external APIs are live when offline, or simulates government approval without official challans.
3. **Statutory Independent Counsel Firewall**: In strict compliance with the Advocates Act, 1961, CraftEgon CCS provides secretarial and digital compliance infrastructure, while all formal litigation advocacy before NCLT/Courts is routed to empanelled independent advocates.
4. **Static-First Performance**: Core content and diagnostic calculators execute client-side with zero dependencies, ensuring sub-second paint times and 100% uptime on Cloudflare Pages.
