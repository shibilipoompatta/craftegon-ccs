## Detailed Remediation Evidence

### 1. Copywriting & Typography (R-02, R-16)
- **Em Dash Elimination (R-02)**: Replaced all occurrences of `—` in production HTML, JS, and CSS files with colons, commas, or periods. The core footer claim now reads:
  `Building business and statutory compliance infrastructure for India's modern enterprises: fixed transparent pricing, dedicated desk support, and institutional speed.`
- **Buzzword Scrubbing (R-16)**: Replaced self-important phrases in `portal/index.html`, `portal/dashboard.html`, and `portal/subscription.html` (e.g. `Autonomous Compliance Calendar OS` -> `Compliance Calendar & Statutory Tracking`).

### 2. Mobile Layout & Responsive Mechanics (R-03)
- **Mobile Sticky Dock Clearance**: Injected in `assets/css/theme.css`:
  ```css
  @media (max-width: 768px) {
    body {
      padding-bottom: calc(68px + env(safe-area-inset-bottom, 0px)) !important;
    }
  }
  ```
- **Tap Targets (R-03 / R-39)**: Enforced `min-height: 44px; display: inline-flex; align-items: center;` on `.if-social-link` and `.fasttrack-pill` in `assets/css/navbar.css`.

### 3. Human Accessibility & Interaction Affordances (R-25, R-39)
- **Interactive Cursor Affordance**: Added universal base layer in `assets/css/theme.css`:
  ```css
  a[href], button:not(:disabled), summary, select, label[for], [role="button"] {
    cursor: pointer;
  }
  button:disabled, input:disabled, select:disabled {
    cursor: not-allowed;
  }
  ```
- **Color Contrast Hardening**: Darkened `--text-light` in `assets/css/tokens.css` from `#708A93` (3.4:1) to `#4A636B` (**4.8:1** contrast on white, WCAG AA compliant).

### 4. UI Polish & Visual De-Cluttering (R-01, R-04, R-09, R-13, R-19)
- **Eyebrow Badges Above H1**: Removed `.hero-pill-badge` in `index.html`, `.hero-badge` in `contact.html`, and `.portal-badge` in `portal/*.html`.
- **Infinite Pulse Loops**: Removed `@keyframes pulse` and `box-shadow` glows on status dots in `assets/css/home-unique.css` and `assets/css/portal.css`.
- **Emoji Replacement**: Removed literal emojis (`⚡`, `💬`, `📞`, `✉️`, `🏢`, `🏛️`, `📊`, `🛡️`, `📋`, `⚖️`, `🧮`) from headers, navigation bars, and buttons.
- **Surface Cleanliness**: Replaced the radial gradient orb in `about.html` with a crisp, low-glare linear gradient `linear-gradient(180deg, #F4FAF7 0%, #FFFFFF 100%)`.
- **Left Stripe Removal**: Converted `border-left: 4px solid ...` on callouts and banners to clean 1px perimeter borders.

### 5. Code Comment Hygiene (antislop-code)
- Stripped 100+ decorative ASCII banner lines (`/* ==================== */`) across `theme.css`, `tokens.css`, `navbar.css`.
- Removed obvious step-by-step narration comments (`// Step 1: ...`, `// Helper function...`) in `forms.js` and `service-search.js`.
