## 3. Discrepancy, Duplication & Hygiene Analysis

### 3.1 Duplicate File: `services.html` vs `services/index.html`
- **Observation:** Both `services.html` and `services/index.html` exist at identical byte sizes (58,161 bytes) and line counts (1,508 lines).
- **Edge Routing Analysis:** `_redirects` contains:
  ```
  /services        /services/index.html    200
  /services/       /services/index.html    200
  /services.html   /services/index.html    200
  ```
- **Problem:** Having two physical identical files on disk invites accidental out-of-sync edits.
- **Blueprint Recommendation:** Preserve `services/index.html` as the canonical destination; make `services.html` a permanent 301 redirect to `/services/`.

### 3.2 Missing Dedicated Standalone Contact Page
- **Observation:** The site has no physical `contact.html` file at root.
- **Problem:** All navigation menus link to `/index.html#contact` or `/conversion/retainer-desk.html`.
- **Blueprint Recommendation:** Create a dedicated, clean, minimal `contact.html` page containing the approved contact details, Service Desk address, and direct enquiry intake.

### 3.3 Exclusion of Portal and Admin Routes
- **Observation:** `portal/*.html` (4 files) and `admin/*.html` (2 files) are physically deployed to the public web root.
- **Blueprint Recommendation:** In accordance with Owner Decisions 4.4 and 4.5, these 6 files must be excised from the public publishing directory and moved to a separate private development branch.

### 3.4 Search Page (`search/index.html`) Redundancy
- **Observation:** `search/index.html` implements simulated MCA master data and trademark lookups using legacy styling.
- **Problem:** It confuses users searching for CCS services, as universal service search already exists in the header and on `services/index.html`.
- **Blueprint Recommendation:** Merge third-party lookup tools into dedicated conversion diagnostic tools or redirect `/search/` to the unified `/services/` directory.
